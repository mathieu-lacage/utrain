A run now freezes the podman image id it was created against instead of only
remembering the image's name. Re-tagging the name to a different image later
no longer changes what the run sees -- its config schema, its phase list --
or what its containers run; `utrain run show` displays the frozen id beside
the name. Runs created before this change are pinned to whatever the name
points at the first time utrain touches them.
