`:` in the TUI opens a goto line at the bottom: a run's name or id prefix goes to
it in Runs (`run/phase` to one of its phases, opening what it is in), `@name` to
a sweep, a workspace's name to that workspace, and `menu` (or `menu sweeps`) opens
a menu -- everything the function keys reach, for a terminal over ssh that does
not send them. Names complete as they are typed; `right` accepts.
