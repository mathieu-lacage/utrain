Every command that takes a run, attempt or phase accepts the same
fully-qualified id, the one the tables print in their first column: `RUN`,
`RUN/ATTEMPT`, `RUN/PHASE` or `RUN/ATTEMPT/PHASE` (a phase without its attempt
belongs to the run's latest attempt). So `utrain run logs 7/2/pretrain` works,
as do `utrain run chat RUN/PHASE` and `utrain run restart RUN/PHASE`, and
`attempt list RUN/ATTEMPT` narrows to one attempt. All the addresses are now
parsed by one shared parser, and `run show`, `run start`, `run stop` and
`run delete` refuse a slash-bearing argument instead of silently using the
part before it.
