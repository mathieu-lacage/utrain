Text in the TUI log pane can be selected and copied: drag across the phase's
output to highlight it, then `ctrl+c` (or `ctrl+shift+c`) to copy. The copy is
offered to the terminal's clipboard and to its primary selection -- the one a
middle-click pastes -- over OSC 52, the only channel a TUI running over ssh
has to the machine the terminal runs on; whether it lands is the terminal
emulator's call, and a terminal that honors neither leaves shift-drag as the
way to select with the terminal's own machinery. The pane was a `RichLog`,
which accepts the drag but can extract no text from what it has rendered, so a
selection there always copied nothing; it is now the one widget Textual gives
working selection to for plain text. The highlight itself keeps its text
readable: Textual's default selection colors draw a solid-looking block over a
transparent foreground, which rendered the selected text in the highlight's
own color.
